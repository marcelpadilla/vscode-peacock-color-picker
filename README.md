# Peacock Color Picker

Minimal color picker for VS Code.

Click the palette in the status bar. Pick a color. Your workspace changes instantly.

> **Requires [Peacock](https://marketplace.visualstudio.com/items?itemName=johnpapa.vscode-peacock).** This is the color picker it does not have.

## Click the palette

![The status bar button](https://raw.githubusercontent.com/marcelpadilla/vscode-peacock-color-picker/main/media/screenshots/statusbar.png)

## Pick a color

![The color menu](https://raw.githubusercontent.com/marcelpadilla/vscode-peacock-color-picker/main/media/screenshots/menu.png)

Arrow keys preview live. Enter keeps it, <kbd>Esc</kbd> puts it back.
Type a hex to use any color.

## Or open the full picker

![The picker](https://raw.githubusercontent.com/marcelpadilla/vscode-peacock-color-picker/main/media/screenshots/picker.png)

Palette, HSV, RGB and OKLCH. Lighten and darken down the left.
